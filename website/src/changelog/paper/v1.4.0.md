# v1.4.0

- Download:
    - [GitHub](https://github.com/m1sk9/LunaticChat/releases/tag/paper/v1.4.0)
    - [Modrinth](https://modrinth.com/plugin/lunaticchat/version/1.4.0)

## New Features

- `/lc reload` now re-reads `config.yml`.
  - A limited set of settings is applied on the spot, without a restart.
  - Some settings, such as the Velocity integration, still require a restart.
- Debug logging has been reworked.
  - Turn it on [in the configuration file](/docs/configuration#debug-logging) or with [the `/lc debug` command](/docs/reference/commands#lc-debug-category-on-off), and each area of the plugin reports what it is doing.
  - On Velocity it is controlled by the `LUNATICCHAT_DEBUG` environment variable.
- `/lc debug` switches debug categories on and off without a restart.
  - After a restart, the value in the configuration file is in charge again.
- `/lc dump` writes a LunaticChat diagnostics report.
  - The report is written to the plugin folder.
  - Please attach this report when you file a bug.
