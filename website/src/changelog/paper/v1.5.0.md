# v1.5.0

- Download:
    - [GitHub](https://github.com/m1sk9/LunaticChat/releases/tag/v1.5.0)
    - [Modrinth](https://modrinth.com/plugin/lunaticchat/version/1.5.0)

## New Features

- Added the `{world}`, `{display_name}`, `{channel_id}` and `{role}` placeholders to `messageFormat`.
  - `{world}` works in `directMessageFormat` and `channelMessageFormat`; the other three work in `channelMessageFormat`.
  - `{display_name}` keeps the colors and hover text that other plugins give the display name, without recoloring the rest of the message.
  - `{role}` is shown in the configured language.
  - See [Placeholders](/docs/reference/message-format#placeholders) for the details.
- Raised the protocol version to `1.0.2`.
  - Cross-server direct messages now carry the world the sender is in.
  - Paper and Velocity can be updated in either order.

## Changes

- [`/lc channel status`](/docs/reference/commands#lc-channel-status) now shows member roles in the configured language instead of `[OWNER]` / `[MOD]`.
- Each release tag now carries exactly one platform: `vX.Y.Z` for Paper / Folia and `velocity/vX.Y.Z` for Velocity.
  - Up to v1.4.0, a `vX.Y.Z` release could contain both JARs. When both platforms are updated together, there are now two GitHub Releases.
  - The download links in earlier release notes have been corrected to match.

## Bug Fixes

- Fixed a channel or player name containing `{message}` or another placeholder being replaced instead of shown as written
- Fixed the update checker never reporting a new release under certain conditions
  - This happened whenever the newest GitHub release was a Velocity release or was not tagged `vX.Y.Z`.

## Notes

- For `{world}` to show in a direct message from another server, the sending server needs Paper v1.5.0 and the proxy needs [Velocity v1.3.1](/changelog/velocity/v1.3.1). Otherwise it is empty.
