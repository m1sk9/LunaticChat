# v1.3.1

- Download:
    - [GitHub](https://github.com/m1sk9/LunaticChat/releases/tag/velocity/v1.3.1)
    - [Modrinth (Velocity)](https://modrinth.com/plugin/lunaticchat/version/1.3.1-velocity)

## New Features

- Cross-server direct messages now pass on the world the sender is in.
  - The `{world}` placeholder therefore works on the receiving server as well. See [Placeholders](/docs/reference/message-format#placeholders).
- Raised the protocol version to `1.0.2`.
  - Paper and Velocity can be updated in either order.

## Changes

- Each release tag now carries exactly one platform: `velocity/vX.Y.Z` for Velocity and `vX.Y.Z` for Paper / Folia.
  - Up to v1.3.0, the Velocity JAR could be published inside a `vX.Y.Z` release together with the Paper one.

## Notes

- `{world}` in a cross-server direct message also needs the sending server to run [Paper v1.5.0](/changelog/paper/v1.5.0). Otherwise it is empty.
