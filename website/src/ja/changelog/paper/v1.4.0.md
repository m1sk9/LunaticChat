# v1.4.0

- Download:
    - [GitHub](https://github.com/m1sk9/LunaticChat/releases/tag/paper/v1.4.0)
    - [Modrinth](https://modrinth.com/plugin/lunaticchat/version/1.4.0)

## New Features

- `/lc reload` で設定ファイルをリロードできるようになりました．
  - 一部の設定に限り，再起動せずにその場で適用が可能です．
  - ただし，Velocity 連携など再起動が必要な設定も一部存在します．
- デバッグ機能を強化しました
  - [設定ファイルで有効する](/ja/docs/configuration#デバッグログ)か[ `/lc debug` コマンド](/ja/docs/reference/commands#lc-debug-category-on-off) で有効にすると各機能のログが出力されるようになりました．
  - Velocity の場合は `LUNATICCHAT_DEBUG` という環境変数で制御可能です．
- `/lc debug` で再起動をせずにデバッグ機能の切り替えができるようになりました．
  - なお，再起動後は設定ファイルの値が評価されるようになっています．
- `/lc dump` で LunaticChat の診断レポートを出力できるようになりました．
  - 診断レポートはプラグインのフォルダーに出力されます．
  - 不具合報告時はこの診断レポートを提出するようにしてください．
