# v1.5.0

- Download:
    - [GitHub](https://github.com/m1sk9/LunaticChat/releases/tag/v1.5.0)
    - [Modrinth](https://modrinth.com/plugin/lunaticchat/version/1.5.0)

## New Features

- `messageFormat` に `{world}`，`{display_name}`，`{channel_id}`，`{role}` のプレースホルダーを追加しました．
  - `{world}` は `directMessageFormat` と `channelMessageFormat` で，残りの 3 つは `channelMessageFormat` で使えます．
  - `{display_name}` は，他のプラグインが表示名に付けた色やホバーテキストをそのまま表示します．メッセージの他の部分の色は変わりません．
  - `{role}` は設定した言語で表示されます．
  - 詳しくは [プレースホルダー](/ja/docs/reference/message-format#プレースホルダー) を参照してください．
- プロトコルバージョンを `1.0.2` に引き上げました．
  - サーバー間ダイレクトメッセージで，送信者がいるワールドを伝えるようになりました．
  - Paper 側と Velocity 側はどちらを先に更新しても問題ありません．

## Changes

- [`/lc channel status`](/ja/docs/reference/commands#lc-channel-status) のメンバーの役割が，`[OWNER]` / `[MOD]` ではなく設定した言語で表示されるようになりました．
- リリースのタグ 1 つにつき，対象のプラットフォームが 1 つになりました．Paper / Folia 版は `vX.Y.Z`，Velocity 版は `velocity/vX.Y.Z` です．
  - v1.4.0 までは，`vX.Y.Z` のリリースに両方の JAR が含まれることがありました．両方を同時に更新する場合は，GitHub Release が 2 つ作られます．
  - これに合わせて，過去のリリースノートの Download リンクを修正しました．

## Bug Fixes

- チャンネル名やプレイヤー名に `{message}` などのプレースホルダーが含まれていると，書いたとおりに表示されず置換されてしまう不具合を修正
- 特定の条件でアップデートチェッカーが新しいリリースを通知しない不具合を修正
  - GitHub の最新リリースが Velocity 版だった場合や，タグが `vX.Y.Z` の形でなかった場合に発生していました．

## Notes

- 別サーバーから届いたダイレクトメッセージで `{world}` を表示するには，送信側のサーバーが Paper v1.5.0，プロキシが [Velocity v1.3.1](/ja/changelog/velocity/v1.3.1) である必要があります．それ以外の場合は空になります．
