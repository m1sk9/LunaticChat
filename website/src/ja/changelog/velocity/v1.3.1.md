# v1.3.1

- Download:
    - [GitHub](https://github.com/m1sk9/LunaticChat/releases/tag/velocity/v1.3.1)
    - [Modrinth (Velocity)](https://modrinth.com/plugin/lunaticchat/version/1.3.1-velocity)

## New Features

- サーバー間ダイレクトメッセージで，送信者がいるワールドを中継するようになりました．
  - これにより，受信側のサーバーでも `{world}` プレースホルダーが使えます．詳しくは [プレースホルダー](/ja/docs/reference/message-format#プレースホルダー) を参照してください．
- プロトコルバージョンを `1.0.2` に引き上げました．
  - Paper 側と Velocity 側はどちらを先に更新しても問題ありません．

## Changes

- リリースのタグ 1 つにつき，対象のプラットフォームが 1 つになりました．Velocity 版は `velocity/vX.Y.Z`，Paper / Folia 版は `vX.Y.Z` です．
  - v1.3.0 までは，Velocity 版の JAR が Paper 版と一緒に `vX.Y.Z` のリリースで公開されることがありました．

## Notes

- サーバー間ダイレクトメッセージで `{world}` を表示するには，送信側のサーバーが [Paper v1.5.0](/ja/changelog/paper/v1.5.0) である必要もあります．それ以外の場合は空になります．
