## Security

- 偽造されたプラグインメッセージがバックエンドに届く問題を修正しました ([GHSA-4p78-89rh-8px5](https://github.com/m1sk9/LunaticChat/security/advisories/GHSA-4p78-89rh-8px5))．
  - 改造クライアントを使うプレイヤーが送ったメッセージを，プロキシが Velocity からのメッセージとしてバックエンドに転送していました．これにより，任意の名前でサーバー間チャットや DM を送ったり，バックエンドを止めたりできました．
  - LunaticChat のプラグインメッセージは，すべてプロキシで処理して転送しないようになりました．

## New Features

  - 同時に Velocity 4.2.x 以前のサポートは終了しました．

## Improvements
